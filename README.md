# concrete-reflective-writing

一个用于中文随笔、日记、短章与独白的 Codex skill。

它从具体生活场景进入，用物象和感官细节承载抽象思考，保留矛盾、不确定与语言的边界，并以克制的方式收束。

## 适用场景

- 把一段经历写成有文学性的反思随笔
- 把零散念头整理成短章或独白
- 修改个人文字，同时保留原有声线
- 将抽象命题落到日常生活现场

不适用于新闻、报告、带货文案或纯知识说明。

## 安装

将 `concrete-reflective-writing` 文件夹复制到 Codex skills 目录：

```text
~/.codex/skills/concrete-reflective-writing
```

之后可直接调用 `$concrete-reflective-writing`，也可由 Codex 在适合的写作请求中自动选择。

## 示例

```text
Use $concrete-reflective-writing 把这段回家经历写成一篇 800 字左右的随笔，保留迟疑感，不要强行升华：……
```

本仓库不包含用于归纳风格的私人笔记或原始素材。
